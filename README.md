## 🚀 Overview

F1 Command Center is a Formula One analytics dashboard designed to simulate the experience of a modern race strategy room.

The platform provides driver intelligence, constructor analytics, race center insights, circuit intelligence, and telemetry-inspired visualizations through a premium user interface.

## ⚡ Getting Started

Clone the repository:

```bash
git clone https://github.com/shakthiganeshp16/f1-command-center.git
```

Navigate into the project:

```bash
cd f1-command-center
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
